The real Oracle handler maps resolve/retry/claim/duplicate/stale to the first five model actions; its stale selector additionally challenges post-oracle sync (no valid model action). The two real rows intentionally have no winning Tier1 proposer, while winner-paid behavior is covered by the separate BondEscalation suites. Healthy callback success, deliberate deferral and both late-API rejection windows are observed; sticky failure checks survive swallowed action reverts. trustedOverrideControl is a deterministic exclusion control. Its independent rows store oracle-first/stale-first expectations and participant/bond baselines. The real Fee handler maps milestone/retryFee/exit to Charge/RetryFee/Settle/Refund. Its two deposits, independent cumulative-gross/fee-policy ghosts, participant baselines, raw remaining and collector/archive/kernel balances establish conservation. Milestone and disputed-exit actions make fresh charges after setup. Four fee-recipient/archive availability combinations cover successful forwarding, fallback and kernel retention. Counters use per-action sink balance deltas, with exact expected counts (two fresh actions for provider-win/split, one for other terminal modes) and zero incompatible counters. No downstream transfer is counted twice. Deterministic tests assert each required branch counter; fail_on_revert=false in stateful tests is never the only completion evidence.

All relevant production writers are covered by the four financial contracts and archive source in coverage.json; interfaces, test fixtures, tool scripts and the inventory itself are also hash-bound. Non-financial registry administration is tested separately, not silently represented by a financial model. Ordinary proposal/finalize bounty mechanics, AI verification, UMA's remote implementation, treasury distributions after receipt and unrelated protocol invariants are outside this skill.

Stale inherited specification was corrected at docs/INVARIANT-COVERAGE.md INV-12/22: missing UMA winner is a clean oracle award with Tier1 refunds, not a split-event path. Some inherited BondEscalation comments about split fallback remain historical wording; executable callback branches and current tests are authoritative within this check. No unrelated production metadata was changed for comment cleanup.

Tier2 late-writer boundary: propose/AI require tier0, challenge/finalize/escalate require tier1; retry does not rewrite ruling. settleUMAAssertion itself rejects resolved disputes before invoking OOV3. The duplicate action drives the direct OOV3 callback no-op, not a post-resolution settleUMAAssertion call. The shared late-result helper handles both APIs/windows; stale mutation proves deferred acceptance, conditional sync proves shared completed acceptance. No separate completed-stale mutation is claimed.

FeeSplit (P3): the real Split handler runs three independent stacks on one token: A = kernel + EscrowVault, D = kernel + FeeSplitVault in profile PAYOUT_ONLY, B = kernel + FeeSplitVault in profile BOTH_AFTER_DISPUTE. Each stack has its own requesters, providers, integrator, paid mediator, fee recipient and archive, and every shared kernel action (milestone, retryFee, eight exit kinds, the requester penalty cancel from COMMITTED, the three block toggles) is applied to all three with per-stack success counters. Stack A is the shadow plain vault of the model. Expected fees are recomputed in the handler from the fee rules (the kernel's cumulative fee, the provider-side rule, the refund-side floors); the vault's quote functions are never read. Credit withdrawals are not mirrored: the handler classifies each attempt per stack as paid, blocked or inapplicable from that stack's own credit and block state and counts any other outcome as unexpected. Model actions map as: Milestone to milestone; Settlement to exit mode 2; PreDisputeRefund to exit modes 0 and 1 and requesterCancelFromCommitted; OpenDispute plus DisputeRefund to exit modes 3-7 (CompositeMediator rulings 0/1/2 with several splitBps, an explicit-proof settle with a paid mediator, an explicit-proof cancel); RetryFee to retryFee; ToggleBlocks to the toggles; the withdrawals to the two withdrawal actions. The model abstracts the bps formulas to fractions (integrator 1/3 of the provider's net, each refund fee 1/4) and has no paid mediator, archive share or bond; those are covered by the real handler and by test/FeeSplitVaultKernel.t.sol. The kernel-view decoding (_readTx) and the void path have no model action: test/FeeSplitVault.t.sol drives them with a fake kernel, outside this skill's runner.
